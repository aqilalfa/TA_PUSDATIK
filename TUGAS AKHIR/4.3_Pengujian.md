**4.3 Pengujian**

Pengujian pada penelitian ini dirancang untuk memastikan bahwa seluruh komponen autentikasi berjalan sesuai alur yang telah ditetapkan. Fokus pengujian tidak hanya berada pada keberhasilan login, tetapi juga pada validasi struktur data hasil autentikasi, pemetaan grup ke role, pembentukan shadow user, serta penerbitan token yang digunakan pada sesi pengguna.

Pada level unit, komponen yang diuji mencakup LDAP provider, role mapper, dan JWT manager. Berkas pengujian yang menjadi rujukan utama berada pada `backend/tests/test_ldap_provider.py`, `backend/tests/test_ldap_real_integration.py`, `backend/tests/test_jwt_manager.py`, dan `backend/tests/test_auth_api.py`. Dari pelaksanaan pengujian lokal, seluruh skenario LDAP yang dijalankan menunjukkan hasil berhasil, sehingga implementasi dianggap stabil pada tahap pengembangan.

Untuk mendekati kondisi nyata, pengujian juga dibagi ke dalam dua pendekatan, yaitu mock LDAP dan real LDAP. Mock LDAP digunakan agar skenario dapat dijalankan secara cepat dan deterministik tanpa ketergantungan pada infrastruktur eksternal, sedangkan real LDAP disiapkan melalui `docker-compose.ldap.yml` dan berkas LDIF bootstrap. Kombinasi kedua pendekatan tersebut memungkinkan proses verifikasi dilakukan secara fleksibel sesuai kebutuhan.

Pengujian keamanan token dilakukan untuk memastikan bahwa token yang kedaluwarsa ditolak, token yang valid dapat diverifikasi, dan refresh cookie disimpan dalam kondisi yang sesuai. Dari perspektif keamanan aplikasi, hal ini penting karena sistem autentikasi tidak hanya bergantung pada suksesnya login, tetapi juga pada ketepatan pengelolaan siklus hidup token.

Perintah berikut digunakan untuk menjalankan pengujian utama.

```bash
cd backend
venv/Scripts/python -m pytest tests/test_ldap_provider.py tests/test_ldap_real_integration.py -v
```

```bash
docker compose -f docker-compose.ldap.yml up --build
```

Potongan berikut menunjukkan contoh pola pengujian yang digunakan sebagai ilustrasi penyusunan skenario UAT.

```python
def test_ldap_auth_success(mock_ldap_server, db_session):
    user = ldap_provider.authenticate("alice", "correcthorsebatterystaple", db_session)
    assert user is not None
    assert "evaluator_spbe" in parse_roles(user.roles)
```

Kutipan langsung dari test aktual memperkuat ruang lingkup pengujian yang dilakukan.

> "Tests: LDAP bind, shadow user provisioning, group→role mapping, retry logic"

> "Verify LDAP provider creates shadow user on first login"

> "Verify user was updated"

> "Test complete LDAP login flow: authenticate → provision → token"

Empat kutipan tersebut menunjukkan bahwa pengujian tidak berhenti pada verifikasi koneksi LDAP semata, tetapi juga mencakup pembentukan shadow user, pembaruan data pengguna, serta alur autentikasi lengkap hingga token diterbitkan. Dengan demikian, kualitas implementasi dapat dinilai dari sisi fungsional maupun konsistensi perilaku sistem.
