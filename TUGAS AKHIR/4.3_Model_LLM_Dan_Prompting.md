**4.3 Model LLM dan Prompting**

Setelah konteks berhasil dibangun melalui retrieval, tahap berikutnya adalah pembangkitan jawaban oleh model bahasa lokal. Sistem ini tidak menggunakan model generatif secara bebas, melainkan menempatkan model di dalam kerangka prompt yang ketat agar jawaban tetap grounded terhadap dokumen referensi. Logika tersebut diatur melalui `backend/app/core/rag/engine/llm_client.py` dan `backend/app/core/rag/prompts.py`.

Model yang digunakan dikonfigurasi melalui parameter lokal pada `backend/app/config.py`, termasuk path model, jumlah layer GPU, ukuran context window, serta parameter sampling dasar. Dengan pengaturan ini, aplikasi dapat berjalan pada lingkungan yang terbatas, tetapi tetap mempertahankan kemampuan generatif yang memadai untuk menjawab pertanyaan berbasis dokumen.

Bagian penting dari implementasi adalah pemilihan system prompt yang berbeda berdasarkan jenis pertanyaan. Untuk pertanyaan pasal dan ayat, sistem menggunakan prompt legal yang sangat ketat agar model tidak mengarang nomor atau daftar yang tidak tersedia pada konteks. Untuk pertanyaan tabel, prompt disusun agar model membaca isi tabel secara literal dan tidak mengubah angka ataupun struktur baris. Sementara itu, pertanyaan umum diarahkan ke prompt generik yang tetap menuntut sitasi dan pembatasan konteks.

Selain prompt dasar, sistem juga menerapkan guardrail tambahan sebelum pertanyaan dikirim ke model. Guardrail ini berfungsi sebagai instruksi tambahan yang dibangun dari isi query dan konteks agar model tidak mudah mengeluarkan klaim bahwa informasi tidak tersedia padahal kata kunci penting sudah ada dalam konteks. Dengan cara ini, sistem berusaha menjaga keseimbangan antara kehati-hatian dan kelengkapan jawaban.

Model juga diakses melalui streaming agar respons awal dapat diterima pengguna dengan cepat. Pengiriman jawaban dilakukan token demi token lewat endpoint Ollama, sehingga pengalaman percakapan terasa lebih responsif dibandingkan menunggu seluruh jawaban selesai dibangkitkan terlebih dahulu.

Potongan kode berikut memperlihatkan bagaimana sistem memilih prompt, menyusun pesan, dan mengirim permintaan ke model.

```python
_PROMPT_MAP = {
    "table": SYSTEM_PROMPT_TABLE,
    "pasal": SYSTEM_PROMPT_LEGAL,
    "indikator": SYSTEM_PROMPT_LEGAL,
    "general": SYSTEM_PROMPT_GENERAL,
}

system_prompt = _PROMPT_MAP.get(query_type, SYSTEM_PROMPT_GENERAL)
quality_guardrail = build_quality_guardrail(query, context)
```

payload = {

Konteks prompting di sistem ini menunjukkan bahwa model bahasa bukan sumber kebenaran utama, melainkan mesin generatif yang dibatasi oleh aturan grounding. Dengan demikian, kualitas jawaban tidak hanya bergantung pada kemampuan model, tetapi juga pada ketepatan prompt, konteks, dan guardrail yang membungkusnya.
